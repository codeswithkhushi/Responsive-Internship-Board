# Responsive Internship Board

A responsive and accessible internship listing website built using HTML, CSS, and JavaScript.

## ✨ Features

* 🔎 Search internships by title, company, domain, or skills
* 🏷️ Filter internships by domain
* 📱 Responsive design for mobile, tablet, and desktop
* 🌙 Dark mode
* 🚫 Empty state when no internships are found
* ⚠️ Error state with retry option
* ⌨️ Keyboard-friendly navigation
* ♿ Accessible form labels and focus states
* 💻 Clean and beginner-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Responsive-Internship-Board/
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. For the best experience, use VS Code Live Server.

## 🎯 Project Goal

The goal of this project is to provide a simple and responsive interface where students can easily explore internship opportunities and filter them according to their interests.
